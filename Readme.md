# Visual Merit or Linguistic Crutch? A Close Look at DeepSeek-OCR
Visual merit or linguistic crutch? We find that DeepSeek-OCR and end-to-end VLMs rely heavily on hallucination to "reconstruct" text. When linguistic priors are removed, the "optical compression" paradigm fails, causing catastrophic degradation in both OCR precision and downstream reasoning.

We design a series of semantic disruption experiments with five key research questions:
1. **RQ1:How does sentence-level semantic disruption affect DeepSeek-OCR?**
By introducing semantically absurd but visually similar sentence-level replacements, we probe global contextual priors' contribution.
2. **RQ2:How does word-level semantic disruption affect DeepSeek-OCR?**
Through intra-word letter swaps, full shuffles, and fully random character sequences devoid of any lexical or syntactic structure, we isolate local priors and measure pure visual contribution.
3. **RQ3:How Does Linguistic Prior Dependence Manifest Across Different VLM and OCR Architectures?**
We benchmark 13 OCR and VLM models with differing architectures on natural vs zero-prior random text to quantify the generality of prior exploitation.
4. **RQ4:How does DeepSeek-OCR perform on QA and VQA tasks?**
We further evaluate semantic fidelity for downstream document reasoning, including visual question answering (VQA) vs pure-text QA.
5. **RQ5:What is the context length limit for optical compression?**
Finally, we stress-test DeepSeek-OCR on real long-form narratives (up to 12,000 tokens) to identify practical scalability limits across its resolution modes.

# Data, Results and Scripts

### 1. Data ([data/](data/))
The [data/](data/) directory contains all datasets used for evaluation:

- **Baselines**:
  - [data/en_png/](data/en_png/): original 112 English document images from the FOX dataset.
  - [data/from_text/](data/from_text/): Clean baseline images generated by rendering ground-truth text into images using our processing pipeline in [src/data_process.py](src/data_process.py).
- **RQ1 (Sentence-level Disruption)**:
  - [data/distort/](data/distort/): Images containing sentence-level perturbations.
  - [data/data.json](data/data.json): The core data file for FOX, including sentence-level disrupted text.
- **RQ2 & RQ3 (Word-level Disruption)**:
  - **Perturbation Types**: `swap` (swapping two letters in a word), `shuffle` (fully shuffling letters in a word), and `random` (sequences of random letters).
  - **Intensity**: Suffixes `_5` and `_10` represent the percentage (5% or 10%) of words modified.
  - **Images**: Located in [data/swap_5/](data/swap_5/), [data/swap_10/](data/swap_10/), [data/shuffle_5/](data/shuffle_5/), [data/shuffle_10/](data/shuffle_10/), and [data/random/](data/random/) folders.
  - **Annotations**: [data/swap_5.json](data/swap_5.json), [data/swap_10.json](data/swap_10.json), [data/shuffle_5.json](data/shuffle_5.json), [data/shuffle_10.json](data/shuffle_10.json), and [data/random.json](data/random.json).
- **RQ4 (Downstream Reasoning)**:
  - [data/qa.json](data/qa.json): Data containing QA (Question Answering) pairs.
- **RQ5 (Long-form Narrative)**:
  - [data/story_images/](data/story_images/): Document images for long-form text.
  - [data/story_txt/](data/story_txt/): 5 full-length source `.txt` files.
  - [data/story_data/](data/story_data/): JSON files containing structured data for the long-text experiments.

### 2. Results ([results/](results/))
This directory contains raw model outputs (JSON) and evaluation results (`_eval.json` files with metrics):

- [results/ocr/](results/ocr/): RQ1 results for FOX original data, clean `from_text` images, and sentence-level perturbations.
- [results/swap_5/](results/swap_5/), [results/swap_10/](results/swap_10/), [results/shuffle_5/](results/shuffle_5/), [results/shuffle_10/](results/shuffle_10/): OCR results and evaluation for word-level disruptions.
- [results/random/](results/random/): OCR results for images composed of entirely random letter sequences.
- [results/qa/](results/qa/) & [results/vqa/](results/vqa/): Results for the QA and Visual Question Answering experiments in RQ4.
- [results/story/](results/story/): OCR outputs and evaluation metrics for the long-text scalability tests (RQ5).
- [results/other/](results/other/): Comparative results and metrics for 11 additional OCR and VLM models used in RQ2.

### 3. Scripts ([src/](src/))
- [src/data_process.py](src/data_process.py): Script for data preparation, including rendering text to images and generating sentence/word-level perturbations.
- [src/eval.py](src/eval.py): Evaluation script used to calculate OCR performance metrics across all experiments.
